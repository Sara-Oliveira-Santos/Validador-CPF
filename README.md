# 📑 Validador de CPF
Fiz esse pequeno projeto básico para consolidar meus conhecimentos sobre **HTML**, **CSS** e **JavaScript**. 

O projeto consiste em uma interface simples onde o usuário digita um CPF (apenas números) e o sistema realiza s cálculo matemático oficial dos dígitos verificadores para validar se o CPF é autêntico ou não.

Você pode testar a aplicação funcionando em tempo real através do link:
**[Acesse a página do projeto aqui](https://sara-oliveira-santos.github.io/Validador-CPF/)**
